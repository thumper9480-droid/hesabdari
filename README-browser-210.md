# نسخهٔ مرورگر ۲۱۰

https://thumper9480-droid.github.io/hesabdari/?v=210

منو: ثبت سند، برنامه، موجودی، گزارش‌ها، گروه‌ها، سرمایه اولیه، افراد، کالاها، معرفی واحدها، معرفی نوع دارایی؛ سپس سایر گزینه‌ها. حساب اشخاص از منو حذف شد؛ داده‌ها محفوظ‌اند. اطلاعات نسخه در پایین نوار کناری قرار گرفت.

در معرفی بانک، حساب بانکی، صندوق، هزینه و درآمد انتخاب برچسب نداریم. در سند، برچسب سند و سطر عملیات جدا دریافت می‌شود؛ فرم فعلی هر بار یک سطر عملیات دارد. گزارش برچسب‌ها هر دو سطح را لحاظ می‌کند.

طبق درخواست قبلی تست اجرا نشد. پس از انتشار Ctrl+F5 بزنید.
