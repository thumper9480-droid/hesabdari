# نسخهٔ ۲۱۲ — تغییر شمارهٔ ۱

منو از نو به‌صورت یک ساختار واحد ساخته شد؛ زنجیرهٔ جابه‌جایی‌های ۲۰۸ تا ۲۱۱ جایگزین شد.

برنامه، موجودی، سرمایه اولیه، ثبت سند، گزارش‌ها؛ سپس گروه‌ها، معرفی‌ها و اطلاعات؛ سپس تاریخ/ساعت و خروج.
گروه‌ها: بانک‌ها، صندوق‌ها، هزینه‌ها، درآمد، اقساط، افراد.
معرفی‌ها: معرفی کالاها، معرفی واحدها، معرفی دارایی، معرفی برچسب‌ها.
اطلاعات: تنظیمات و سوابق، پشتیبانی و بازیابی، آپدیت‌ها.

همان دکمه‌ها و مقصدهای عملیاتی اصلی حفظ شدند. هیچ دادهٔ حسابداری یا فرمولی تغییر نکرد. منوی معرفی‌ها شناسهٔ جدید دارد و با CSS حذف منوی قدیمی تداخل ندارد. حساب اشخاص و تاریخچهٔ تغییرات اسناد به منو برنگشتند؛ سوابقشان محفوظ است. نسخه فقط در تب مرورگر نمایش داده می‌شود. ساعت زنده و مبنای زمانی قبلی حفظ شدند؛ عبارت وقت ایران نمایش داده نمی‌شود.

تست طبق درخواست قبلی اجرا نشد. بررسی نحوی JavaScript انجام شد. آماده‌شدن انتشار عمومی GitHub Pages از این محیط قابل تأیید نیست؛ ارسال شاخه‌ها به‌طور جداگانه تأیید می‌شود.
