# پرامپت شمارهٔ 39: اطلاعات نسخه در تب؛ تاریخ و ساعت زیر لوگو

نسخهٔ ۵.۹.۱، نسخه مرورگر و شمارهٔ واقعی آپدیت فقط در عنوان تب مرورگر نمایش داده شوند. روز هفته، تاریخ و ساعت زنده زیر لوگوی محمد صدرا قرار بگیرند. عبارت وقت ایران از ساعت نوار کناری حذف شود؛ مبنای زمانی ساعت تغییر نکند.

مجوز اجرا: «وقت انجامه.»
