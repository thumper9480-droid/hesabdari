# دستور جاری کاربر

تغییرات جدید شماره‌گذاری و ثبت شوند؛ تا دستور «وقت انجامه» یا دستور صریح اجرا، اجرا نشوند.

تغییرهای ۱ تا ۱۰ قبلاً اجرا شدند. تغییرهای ۱۱ تا ۱۶ با دستور صریح «تغییرات را اعمال کن، نسخه بعدی را بده» در نسخهٔ ۲۱۷ اجرا شدند. شمارهٔ بعدی ۱۷ است. خرید و فروش همچنان منتظر جزئیات‌اند؛ دریافت و پرداخت ارزی و کالایی فعال است.

درخواست قبلی عدم اجرای مجموعهٔ کامل تست‌ها رعایت شد؛ بررسی محدود و مستقل مالی و مرورگر برای نسخهٔ ۲۱۷ انجام شد. داده‌های کاربر برای بررسی استفاده نشدند.
