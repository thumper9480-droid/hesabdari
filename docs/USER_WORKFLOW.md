# دستور جاری کاربر

تغییرات جدید شماره‌گذاری و ثبت شوند؛ تا دستور «وقت انجامه» یا دستور صریح اجرا، اجرا نشوند.

تغییرهای ۱ تا ۲۸ در نسخه‌های قبلی و تغییرهای ۲۹ تا ۳۷ با دستور «وقت انجامه» در نسخهٔ ۲۱۹ اجرا شدند. شمارهٔ بعدی ۳۸ است. تغییر ۳۳ جایگزین محدودیت ارتفاع تغییر ۲۶ است.

هر سطر با Enter در توضیحات قطعی است؛ فاکتور خالی ذخیره نمی‌شود. دکمهٔ ثبت سطر/ثبت نهایی وجود ندارد. میان‌بر منفی در مقادیر عددی سه صفر وارد می‌کند. بانک/صندوق ارزی فقط دریافت/پرداخت ارز و صندوق کالایی فقط دریافت/پرداخت کالا دارد. خرید و فروش سایر طرف‌ها همچنان منتظر مشخصات‌اند.

مجموعهٔ کامل تست‌ها مطابق درخواست قبلی اجرا نشد؛ بررسی محدود مستقل مالی و مرورگر انجام شد. داده‌های کاربر برای بررسی استفاده نشدند.
