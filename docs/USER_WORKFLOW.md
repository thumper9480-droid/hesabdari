# دستور جاری کاربر

دستور قبلی انتظار برای «وقت انجامه» با دستور جدید کاربر جایگزین شده است: «تغییراتی که از الان به بعد می‌دم را ذخیره کن و اجرا کن. تغییر شماره یک.»
تغییرات جدید ثبت و بلافاصله اجرا شوند، مگر کاربر برای همان پیام فقط توضیح یا بررسی برداشت را خواسته باشد. شماره‌گذاری جدید از تغییر شمارهٔ ۱ در docs/changes آغاز می‌شود. شماره‌های docs/requests تاریخچهٔ قبلی هستند.
