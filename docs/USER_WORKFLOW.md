# دستور جاری کاربر

تغییرات جدید شماره‌گذاری و ثبت شوند؛ تا دستور «وقت انجامه» یا دستور صریح اجرا، اجرا نشوند.

تغییرهای ۱ تا ۱۶ در نسخه‌های قبلی و تغییرهای ۱۷ تا ۲۷ با دستور «وقت انجام» اجرا شدند. تغییر ۲۸ نیز پس از توضیح و تأیید صریح کاربر در همان نسخهٔ ۲۱۸ اجرا شد. شمارهٔ بعدی ۲۹ است.

هر سطر با Enter در آخرین فیلد قطعی است؛ دکمه‌های ثبت سطر و ثبت نهایی سند وجود ندارند. خرید و فروش برای طرف‌های غیر بانک/صندوق هنوز منتظر مشخصات‌اند و ثبت نمی‌شوند. بانک و صندوق ارزی فقط دریافت/پرداخت ارز، صندوق کالایی فقط دریافت/پرداخت کالا دارد.

مجموعهٔ کامل تست‌ها مطابق درخواست قبلی اجرا نشد؛ بررسی محدود مستقل موتور مالی و مرورگر برای این تغییر انجام شد. اطلاعات کاربر مبنای بررسی نبودند.
