# دستور جاری کاربر

دستور جدیدتر کاربر جایگزین اجرای فوری شده است: «تغییرات را شماره گزاری کن و تا نگفتم وقت انجامه انجام نده».

تغییرات جدید ثبت و شماره‌گذاری شوند؛ تا دستور صریح «وقت انجامه» اجرا نشوند. دستور اجرا برای تغییرهای ۲ و ۳ دریافت و آن‌ها در نسخهٔ ۲۱۳ تکمیل شدند. شمارهٔ تغییر جدید بعدی ۴ است.

شماره‌گذاری فعلی در docs/changes قرار دارد؛ docs/requests تاریخچهٔ شماره‌گذاری قدیمی است. دستور قبلی عدم اجرای تست همچنان رعایت شده؛ این انتشار فقط بررسی نحوی JavaScript دارد.
