# تغییر شمارهٔ 64

ارزها مانند تومان، دلار و یورو فقط در معرفی ارزها نمایش داده شوند. معرفی واحدها فقط واحدهای شمارش/وزن مانند عدد، گرم و کیلوگرم را نمایش دهد؛ واحدهای داخلی ارز برای سلامت ارتباط سوابق حفظ شوند.

وضعیت: اجرا در نسخهٔ ۲۲۱؛ تغییرهای ۴۳ تا ۶۳ با «وقت انجامه» و تغییر ۶۴ با دستور مستقیم حذف نمایش تکراری ارزها.
