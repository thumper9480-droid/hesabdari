# 130 — اصلاح دو Enter منوی اصلی

کلیدهای منوی راست در نخستین handler پنجره و قبل از handlerهای قدیمی رسیدگی می‌شوند. بالا/پایین میان گزینه‌های قابل مشاهده جابه‌جا می‌شود؛ Enter اول گزینه را مشخص و Enter دوم صفحه را باز می‌کند. برای عنوان زیرمنو، Enter اول زیرمنو را باز و Enter دوم نخستین صفحهٔ زیر آن را باز می‌کند؛ با بالا/پایین می‌توان صفحهٔ دیگری را انتخاب کرد. نگه‌داشتن Enter به‌جای دو فشار مستقل، ورود را فعال نمی‌کند. ESC انتخاب تأییدنشده را پاک و تمرکز را به منو می‌برد.

وضعیت: با «وقت انجامه» اجرا و تست شد؛ نسخهٔ ۲۲۸.
