# تغییر شمارهٔ 32

فرم معرفی واحدها فقط نام، نوع (تعدادی/وزنی) و برای وزنی معادل هر واحد به گرم داشته باشد. اطلاعات فنی و دقت ذخیره‌شدهٔ واحدهای قدیمی حفظ شود؛ دقت داخلی واحد وزنی تازه ۸ و تعدادی تازه صفر است، بدون نمایش تنظیمات اضافی. ارزهای موجود واحد خود را حفظ می‌کنند و مدیریت ارز در منوی ارزهاست.

وضعیت: اجرا در نسخهٔ ۲۱۹ با دستور «وقت انجامه».
