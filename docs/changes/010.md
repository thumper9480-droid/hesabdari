# تغییر شمارهٔ 10: پرداخت ارزی

پرداخت ← نوع پرداخت ارزی/کالایی ← نوع ارز ← محل/طرف پرداخت: بانک‌ها، صندوق‌ها، هزینه‌ها، درآمد، اقساط، افراد ← فیلدهای وابسته ← مقدار ارز پرداختی ← برچسب سطر ← توضیحات. کلمهٔ خزانه‌ها با توضیح کاربر به هزینه‌ها اصلاح شد.

دستور اجرا: «Wachte einjomme.» در متن گفتگو به «وقت انجامه» تعبیر شد و کاربر سپس جزئیات مسیر اقساط را برای اجرا تأیید کرد.

وضعیت: اجرا در نسخهٔ ۲۱۶.
