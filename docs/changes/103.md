# ۱۰۳ — منوی رویدادها و تاریخچهٔ خوانای حذف و اصلاح اسناد

- نام منو و عنوان صفحهٔ «تنظیمات و سوابق» به «رویدادها» تغییر کند.
- برای حذف سند یا سطر، شماره فاکتور، طرف حساب، اطلاعات کامل سطرهای حذف‌شده و تاریخ و ساعت حذف قابل مشاهده باشد؛ فقط شناسهٔ فنی یا نام عملیات نمایش داده نشود.
- برای اصلاح سند یا سطر، مشخصات قبل و بعد کنار هم نمایش داده شوند و فیلدهای تغییرکرده قابل تشخیص باشند.
- حذف کامل فاکتور و حذف یک سطر از هم قابل تشخیص باشند؛ معلوم شود کدام فاکتور و کدام سطر تغییر کرده است.
- حذف یا اصلاح اصل سند نباید سابقهٔ همان رویداد و دادهٔ لازم برای نمایش قبل/بعد را از بین ببرد.
- اطلاعات و عنوان عملیات به فارسی و خوانا نمایش داده شوند؛ تاریخ و ساعت نیز مطابق قواعد فارسی برنامه باشند.
- دربارهٔ سوابق قدیمی، فقط اطلاعاتی که واقعاً ذخیره شده‌اند نمایش داده شود؛ نسخهٔ قبل/بعد یا زمان ناموجود ساخته نشود و نبود اطلاعات روشن بیان شود.
- تغییر نام منو به‌تنهایی مجوز حذف سایر امکانات موجود صفحه نیست؛ تنظیمات یا ابزارهای فعلی بدون درخواست صریح کنار گذاشته نشوند.

وضعیت: اجرا و تست شد؛ نسخهٔ ۲۲۴.
