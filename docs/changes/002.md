# تغییر شمارهٔ ۲: جایگاه اقساط

اقساط فقط در زیرمنوی گروه‌ها قرار بگیرد و در منوی اصلی نمایش داده نشود. دستور اجرا: وقت انجامه.

در نسخهٔ ۲۱۳ علاوه بر ساختار ۲۱۲، کنترل تک‌گزینه‌بودن، انتقال مجدد در پایان بارگذاری یا تغییرات مستقیم نوار کناری و منع نمایش سطح اصلی اضافه شد. عملکرد قبلی همان دکمه حفظ شد.
