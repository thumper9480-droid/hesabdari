# ۹۳ — نمایش موجودی به تفکیک کالا، صندوق و جمع‌های نهایی

- برای کالاهای وزنی و وزنی–تعدادی، نام صندوق، نام کالا، عیار واقعی، وزن واقعی و وزن معادل عیار ۷۵۰ نمایش داده شود.
- برای کالاهای تعدادی، نام صندوق، نام کالا و تعداد نمایش داده شود.
- برای ارزها، بانک/شماره حساب یا صندوق نگهدارنده، نام ارز و مقدار موجودی قابل مشاهده باشد.
- پایین جدول‌ها مجموع موجودی طلا به گرم معادل عیار ۷۵۰ نمایش داده شود. طلا با نقره یا جنس‌های دیگر جمع نشود؛ جنس‌های دیگر مستقل بمانند.
- مجموع هر ارز، مانند تومان، دلار و یورو، جدا نمایش داده شود؛ ارزها بدون تبدیل مشخص با هم جمع نشوند.
- مجموع تعداد هر کالای تعدادی بر اساس نام/شناسهٔ همان کالا جدا نمایش داده شود؛ تعداد کالاهای متفاوت مخلوط نشود.
- وزن واقعی قطعه و عیار آن برای موجودی فیزیکی حفظ شوند؛ معادل ۷۵۰ فقط مبنای تبدیل/جمع مربوط است.
- فقط موجودی واقعی وارد این گزارش شود؛ خرید و فروشِ بدون دریافت/پرداخت، موجودی ایجاد یا کم نکنند. اطلاعات قطعه، انگ و ری‌گیری موجود از بین نرود.

وضعیت: اجرا و تست شد؛ نسخهٔ ۲۲۴.
