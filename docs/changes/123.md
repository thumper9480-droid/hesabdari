# 123 — معرفی کالای وزنی

نوع کالا، جنس، عیار ثابت یا متغیر، مبنای تسویهٔ نمایشی وزن و کارمزد نمایش داده می‌شوند. مبنای کارمزد بدون انتخاب اضافی، درصد وزن همان سطر است. درصد ثابت در معرفی و درصد متغیر در سطر سند وارد می‌شود؛ وزن ضرب درصد تقسیم بر صد، کارمزد وزنی است. گزینهٔ نامتناسب کارمزد هر عدد در معرفی کالای وزنی جدید وجود ندارد. ویژگی آب‌شده و عیار متغیر حفظ است.

وضعیت: با دستور «این را اجرا کن» اجرا و تست شد؛ نسخهٔ ۲۲۷.
