# ۹۲ — نمایش فشردهٔ مانده‌ها در چاپ فاکتور

- سه بخش «ماندهٔ قبل از فاکتور»، «اثر این فاکتور» و «ماندهٔ بعد از فاکتور» در خروجی چاپ وجود داشته باشند.
- به‌جای کارت‌های بزرگ و پر‌فاصلهٔ صفحه، این اطلاعات در جدول کم‌حجم نمایش داده شوند: هر دارایی یک ردیف و سه مقدار قبل، اثر و بعد در ستون‌های کنار هم.
- نام دارایی، واحد، علامت مقدار و وضعیت طلبکار/بدهکار قابل تشخیص بمانند؛ برای طلا مبنای عیار ۷۵۰ حفظ شود.
- مقدارها از همان مانده‌های نمایش فاکتور خوانده شوند؛ برای فشرده‌سازی، محاسبات یا اثر سند تغییر نکند.
- این درخواست مربوط به قالب چاپ است؛ حذف خودسرانهٔ پنل‌های صفحه یا تفسیر آن به‌عنوان پاسخ مورد ۹۱ مجاز نیست.

وضعیت: اجرا و تست شد؛ نسخهٔ ۲۲۴.
