# تغییر شمارهٔ 27

محتوای صفحه گزارش‌ها با انتخاب گروه جایگزین شود: بانک‌ها همه/بانک/حساب؛ صندوق‌ها همه/خاص؛ هزینه‌ها همه/خاص (محل برای تفکیک نام مشابه)؛ درآمدها همه/خاص؛ اقساط همه/قرارداد؛ افراد همه/گروه/فرد. تنها فیلدهای همان گروه نمایش یابند. سوابق حذف نشوند و جمع‌ها به تفکیک دارایی، عیار و دفتر باشند.

وضعیت: اجرا در نسخهٔ ۲۱۸ با دستور صریح کاربر.
