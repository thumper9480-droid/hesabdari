# تغییر شمارهٔ 9: دریافت ارزی

دریافت ← نوع دریافت ارزی/کالایی ← نوع ارز از تمام دارایی‌های ارزی معرفی‌شده ← محل/طرف دریافت از بانک، صندوق، هزینه، درآمد، اقساط، افراد ← فیلدهای وابسته تا انتخاب نهایی ← مقدار ارز دریافتی ← برچسب سطر ← توضیحات. جزئیات کالایی هنوز ارائه نشده و اجرا نمی‌شود.

دستور اجرا: «Wachte einjomme.» در متن گفتگو به «وقت انجامه» تعبیر شد و کاربر سپس جزئیات مسیر اقساط را برای اجرا تأیید کرد.

وضعیت: اجرا در نسخهٔ ۲۱۶.

تأییدهای صریح کاربر برای اقساط:
۱. انتخاب قرارداد، سپس قسط همان قرارداد و کاهش ماندهٔ همان قسط.
۲. بانک یا صندوق سربرگ، محل واقعی ورود/خروج پول باشد و طرف قرارداد از خود قسط مشخص شود.

اقساط جدید (نسخهٔ ۲۱۴ به بعد) در انتخابگر سطر قابل تسویه‌اند. قراردادهای قدیمی همچنان از مسیر قبلی مشاهده و تسویه می‌شوند؛ شناسه‌ها و سوابق آن‌ها بازنویسی نشده‌اند.
