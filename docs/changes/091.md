# ۹۱ — حذف خلاصهٔ مسیرهای زیر سربرگ

کاربر در جریان اجرا با تصویر مشخص کرد که منظور، بخش تکراری «از کجا → به کجا» زیر سربرگ است. همین بخش حذف شد؛ پنل اثر فاکتور و ستون‌های از کجا/به کجا داخل جدول باقی ماندند. تکرار جداگانهٔ مسیرها بالای چاپ نیز حذف شد؛ مسیر هر سطر در خود جدول چاپ وجود دارد.

وضعیت: با توضیح تصویری کاربر مشخص، اجرا و تست شد؛ نسخهٔ ۲۲۴.
