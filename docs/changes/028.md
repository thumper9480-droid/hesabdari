# تغییر شمارهٔ 28

توضیح جدید پس از دستور اجرای ۱۷ تا ۲۷ مطرح و سپس اجرای آن نیز صریحاً تأیید شد: بانک و صندوق ارزی فقط دریافت/پرداخت ارز؛ صندوق کالایی فقط دریافت/پرداخت کالا. خرید و فروش برای تمام بانک‌ها و صندوق‌ها در فهرست نباشد. نوع کالایی برای سربرگ بانک/صندوق ارزی و نوع ارزی برای صندوق کالایی نمایش داده نشود. طرف سطر نیز فقط بانک/صندوق سازگار با ماهیت و ارز معرفی‌شده را نشان دهد؛ اعتبارسنجی مالی مستقل برقرار بماند.

وضعیت: اجرا در نسخهٔ ۲۱۸ با دستور صریح کاربر.
