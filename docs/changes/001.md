# تغییر شمارهٔ ۱ — ساختار تأییدشدهٔ منو

قانون جدید کاربر: تغییرات از این مرحله ثبت و بلافاصله اجرا شوند؛ شماره‌گذاری جدید از ۱ آغاز شده است.

ترتیب منوی اصلی:
۱. برنامه
۲. موجودی
۳. سرمایه اولیه
۴. ثبت سند
۵. گزارش‌ها
۶. گروه‌ها: بانک‌ها، صندوق‌ها، هزینه‌ها، درآمد، اقساط، افراد.
۷. معرفی‌ها: معرفی کالاها، معرفی واحدها، معرفی دارایی، معرفی برچسب‌ها.
۸. اطلاعات: تنظیمات و سوابق، پشتیبانی و بازیابی، آپدیت‌ها.
۹. روز، تاریخ و ساعت زنده.
۱۰. خروج.

معرفی حساب‌ها و کالاها به‌صورت مستقل در منوی اصلی نباشند. اطلاعات و مقصدهای عملیاتی قبلی حفظ شوند. شناسهٔ جدید منوی معرفی‌ها sadraIntroductionsMenu است تا با قانون قدیمی حذف introductionMenu تداخل نکند. عنوان تب نسخهٔ واقعی ۲۱۲ را نشان می‌دهد.

وضعیت: در نسخهٔ ۲۱۲ اعمال شد. طبق درخواست قبلی تست اجرا نشده؛ بررسی نحوی JavaScript انجام شد.
