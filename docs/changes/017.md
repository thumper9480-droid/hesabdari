# تغییر شمارهٔ 17

فاکتورهای قبلی فقط خواندنی باشند. F3 اول اصلاح را فعال کند و ↑/↓ بین سطرها جابه‌جا شوند؛ F3 دوباره ویرایش سطر انتخاب‌شده را باز کند. دکمه‌های سطر، F2/F4 و جزئیات مالی نباید قفل را دور بزنند. ESC یک مرحلهٔ رابط به عقب برگردد و بدون ثبت یا حذف خودکار باشد.

وضعیت: اجرا در نسخهٔ ۲۱۸ با دستور صریح کاربر.
