# تغییر شمارهٔ 48

برای کالای وزنی با عیار متغیر، دریافت با وزن واقعی، عیار، انگ و ری‌گیری و پرداخت بخشی از قطعهٔ انتخابی با کنترل ماندهٔ همان قطعه فراهم شود. بالا/پایین روی وزن پرداخت فهرست قطعه‌ها را باز کند.

وضعیت: اجرا در نسخهٔ ۲۲۱؛ تغییرهای ۴۳ تا ۶۳ با «وقت انجامه» و تغییر ۶۴ با دستور مستقیم حذف نمایش تکراری ارزها.
