# 110 — جدول ماهانهٔ اقساط

زیر صفحهٔ اقساط، جدول سال/ماه/جمع ماه و ستون هر قرارداد ایجاد شد. مبنا صریحاً ماندهٔ پرداخت‌نشدهٔ اقساط در ماه سررسید است؛ جمع کل بالای جدول، ماه‌های شمسی مرتب، سرستون سبز تیره و ردیف‌های متناوب دارد. با پرداخت، اصلاح و حذف به‌روز می‌شود. دارایی‌ها/ارزهای متفاوت جدول و جمع جدا دارند.

وضعیت: اجرا و با دادهٔ مصنوعی تست شد؛ نسخهٔ ۲۲۵، ۲۰۲۶/۱۰/۱۷.
