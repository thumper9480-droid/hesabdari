# ۹۹ — واحد مقدار مطابق معرفی کالا و فقط نمایشی

- با انتخاب هر کالا در سطر سند/فاکتور، واحد مقدار از معرفی همان کالا تعیین شود.
- واحد در سند قابل تغییر نباشد و فقط به‌صورت خوانا نمایش داده شود؛ گزینه‌های گرم، کیلوگرم، مثقال و غیره برای تعویض واحد آن سطر نشان داده نشوند.
- مقدار/وزن و تعداد طبق نوع کالا قابل ورود یا محاسبه بمانند؛ ثابت‌شدن واحد نباید فیلد مقدار را غیرقابل استفاده کند.
- برای وزنی–تعدادی، تعداد در وزن ثابت هر قطعه طبق تعریف کالا محاسبه شود و نتیجه با واحد تعریف‌شده نمایش داده شود.
- واحدهای داخلی، تبدیل‌های لازم برای محاسبه و اسناد قدیمی حذف یا خودسرانه بازنویسی نشوند؛ اسناد قدیمی نیز با واحد ثبت‌شدهٔ واقعی خود نمایش داده شوند.

وضعیت: اجرا و تست شد؛ نسخهٔ ۲۲۴.
