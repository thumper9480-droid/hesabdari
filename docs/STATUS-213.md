# نسخهٔ ۲۱۳ — تغییرهای ۲ و ۳

اقساط فقط داخل گروه‌ها و پشتیبانی و بازیابی فقط داخل اطلاعات است. ساختار قبلی از قبل این مقصدها را داشت؛ در این اصلاح جلوی نمایش سطح اصلی و تکرار احتمالی گرفته شده و جایگاه دکمه‌های اصلی در پایان بارگذاری و تغییرات مستقیم نوار کناری حفظ می‌شود. هیچ تغییر داده یا فرمولی ایجاد نشده است.

طبق درخواست قبلی تست اجرا نشد؛ فقط بررسی نحوی JavaScript انجام شد. ارسال گیت‌هاب با آماده‌بودن عمومی GitHub Pages یکسان نیست.
