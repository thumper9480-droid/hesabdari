# نسخهٔ مرورگر ۲۰۶

https://thumper9480-droid.github.io/hesabdari/

پس از انتشار Ctrl+F5 بزنید. اطلاعات در مرورگر همین دستگاه ذخیره می‌شوند؛ پیش از استفاده پشتیبان بگیرید.

- گروه‌ها ← درآمدها: فقط نام درآمد.
- ثبت سند و حواله ← ثبت طلب درآمدی: عنوان درآمد، شخص بدهکار، دارایی و مقدار طلب؛ بدون افزایش موجودی صندوق.
- ثبت سند و حواله ← دریافت طلب درآمدی: انتخاب طلب، دارایی و مقدار دریافتی، صندوق یا حساب بانکی مقصد. دریافت بخشی از طلب مجاز است. در دریافت دارایی متفاوت، نرخ و شرح توافق تبدیل الزامی است. نرخ یعنی هر واحد دریافتی معادل چند واحد دارایی طلب است. مبالغ را به واحد همان دارایی وارد کنید؛ تومان و ریال مستقل‌اند.
- معرفی کالا: کارمزد ثابت یا متغیر؛ درصد از وزن فاکتور یا مبلغ هر عدد. تنظیمات جدید فعلاً ذخیره می‌شوند و جایگزین فرمول‌های قبلی اسناد نشده‌اند.
- منوی معرفی‌ها همراه زیرمنوها حذف شد. داده‌های قبلی پاک نشدند.

طبق درخواست کاربر، تست اجرا نشده است. این نسخه آزمایشی است.
