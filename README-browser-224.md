# حسابداری محمد صدرا — آپدیت ۲۲۴

تغییرهای ۸۸ تا ۱۰۴ اجرا شدند: ترتیب و فیلترهای کالایی گزارش، موجودی به تفکیک صندوق/کالا/عیار و جمع‌های مستقل، خریدوفروش ارز و کالا بدون تغییر موجودی، واحد نمایشی مطابق معرفی، حذف طرف تکراری و رویدادهای خوانای حذف/اصلاح.

ESC یا F1 به منوی اصلی می‌رود؛ بالا/پایین و Enter برای انتخاب صفحه است. F12 ریزگزارش طرف سربرگ را باز می‌کند. فاکتور جدید از دکمهٔ «فاکتور جدید» ایجاد می‌شود. Enter در آخرین فیلد سطر، ثبت قطعی است. برای اصلاح فاکتور و سپس سطر F3 بزنید. در پرداخت آب‌شده، بالا/پایین روی وزن انتخاب قطعه را باز می‌کند.

چاپ شامل جدول فشردهٔ ماندهٔ قبل/اثر/بعد است. پیام ثبت موقت است و کادر پشتیبان بالای صفحات حذف شده؛ پشتیبان‌گیری از پشتیبانی و بازیابی باقی است. اطلاعات در همین مرورگر است؛ پشتیبان بگیرید. سوابق قدیمی فاقد قبل/بعد ساخته نمی‌شوند.

index.html، next-core.js، next-forms.js، next-report.js، next-ui.js، next-ui.css و fonts کنار هم باشند. تست منبع: node --test tests/*.test.cjs. تست مرورگر اختیاری: SADRA_BASE_URL=http://127.0.0.1:8014/ node tests/browser224.cjs (سرور محلی، Chromium و Playwright محیط لازم‌اند).
