# حسابداری صدرا — نسخهٔ مرورگر ۲۰۵

نشانی سایت: https://thumper9480-droid.github.io/hesabdari/

پس از انتشار Ctrl+F5 بزنید و پیش از تغییر داده‌ها پشتیبان بگیرید. اطلاعات در مرورگر همان دستگاه ذخیره می‌شوند.

این مرحله فقط معرفی‌های منوی «گروه‌ها» را ساده می‌کند:
- صندوق: نام و نوع ارزی یا کالایی؛ بدون محل نگهداری.
- هزینه: این هزینه مربوط به کجاست و این هزینه چیست؛ مدیریت محل‌های دلخواه جداگانه در همان صفحه.
- درآمد: ارزی یا کالایی، عنوان نوع درآمد، محل مربوطه؛ محل‌ها قابل تعریف‌اند.
- کالا: گروه، نام، نوع تعدادی یا وزنی–تعدادی یا وزنی؛ عیار و وزن هر قطعه به گرم و داشتن کارمزد ثابت/متغیر بر حسب نوع کالا.
- برچسب: فقط نام.

مشخصات جدید کالاها فعلاً فقط برای معرفی ذخیره می‌شوند. طبق دستور کاربر، فرمول‌ها، اسناد، موجودی و ماندهٔ اشخاص تغییر نکرده‌اند. کالاهای تازه معرفی‌شده تا مرحلهٔ اتصال بخش‌ها وارد عملیات مالی نمی‌شوند. مشخصات قدیمی محاسباتی کالاها و اسناد محفوظ‌اند؛ داده‌های محل و سرفصل‌های قبلی پاک نشده‌اند. نمایش موجودی بر اساس عیار و اتصال کارمزد جدید به سند برای مرحلهٔ بعد باقی مانده‌اند.

برای اجرای محلی فایل‌ها را کنار هم نگه دارید و index.html را باز کنید، یا از python3 -m http.server 8002 استفاده کنید.
