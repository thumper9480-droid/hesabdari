# نسخهٔ مرورگر ۲۱۴

https://thumper9480-droid.github.io/hesabdari/?v=214

گروه‌ها ← اقساط: نام قرارداد، اثر در ریزحساب، بدهکار شدم/طلبکار شدم، طرف حساب وابسته، تعهد ارزی/کالایی، مقدار هر قسط، تعداد، اولین سررسید شمسی، برچسب و ثبت. سررسیدهای بعدی ماهانه‌اند. تعهد صندوق/بانک موجودی فیزیکی ایجاد نمی‌کند. برای قراردادهای قبلی مسیر مشاهده و تسویه حفظ شده است.

ثبت سند: شمارهٔ جدید، تاریخ شمسی و طرف حساب. Enter از شماره به سال، ماه، روز و گروه طرف حساب می‌رود. در نام هزینه و فرد جست‌وجو کنید؛ برای ساخت مورد جدید ++ وارد کنید. سربرگ پیش‌نویس و بدون اثر مالی است؛ ردیف‌های سند در مرحلهٔ بعد تعریف می‌شوند. اسناد قبلی در گزارش‌ها محفوظ‌اند.

علت برگشت ترتیب منو، اجرای دستور قدیمی هنگام load بود و در ساختار جدید متوقف شد.

فایل next-forms.js باید کنار next-core.js، next-ui.js، next-ui.css و index.html باشد. اطلاعات همچنان در مرورگر همان دستگاه ذخیره می‌شوند. قبل از استفاده پشتیبان بگیرید.

مجموعهٔ تست‌ها و آزمون محاسباتی طبق درخواست قبلی اجرا نشد. بارگذاری، ظاهر، Enter و بازشدن فرم ++ در مرورگر محلی بررسی شدند. انتشار عمومی GitHub Pages ممکن است با تأخیر آماده شود.
