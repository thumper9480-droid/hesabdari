# حسابداری محمد صدرا — نسخهٔ مرورگر، آپدیت ۲۱۸

تغییرهای ۱۷ تا ۲۸: ثبت فوری سطر با Enter در آخرین فیلد (توضیحات)، بدون دکمه‌های ثبت سطر و ثبت نهایی؛ قفل فاکتور قبلی تا F3، انتخاب سطر با بالا/پایین و F3 دوم برای ویرایش؛ ESC مرحلهٔ قبل. مانده‌های قبل/بعد و تأثیر فاکتور، عیار، علامت مقدار و تعداد، واحد مستقل و جزئیات کارمزد نمایش داده می‌شوند.

گزارش‌ها بر اساس بانک، صندوق، هزینه، درآمد، اقساط و افراد هستند. بانک و صندوق ارزی فقط دریافت و پرداخت ارز؛ صندوق کالایی فقط دریافت و پرداخت کالا؛ خرید/فروش با بانک یا صندوق نمایش داده نمی‌شود. مسیر خرید/فروش دیگر طرف‌ها هنوز منتظر مشخصات است.

F1 فاکتور تازه؛ F2 سطر تازه؛ F3 فعال‌کردن اصلاح و سپس ویرایش سطر انتخاب‌شده؛ F4 حذف فاکتور؛ F5 چاپ. در فاکتورهای قبلی ابتدا F3 بزنید. هر ثبت/اصلاح/حذف سطر فوراً اثر مالی دارد. محدودیت موجودی منفی و وابستگی فعال برقرار است.

index.html را همراه فایل‌های next-core.js، next-forms.js، next-ui.js، next-ui.css و پوشهٔ fonts نگه دارید. نسخهٔ آنلاین از GitHub Pages ارائه می‌شود. اطلاعات در مرورگر ذخیره می‌شود؛ برای انتقال از پشتیبانی و بازیابی پشتیبان بگیرید.
