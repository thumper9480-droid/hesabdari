# حسابداری محمد صدرا — آپدیت ۲۲۳

گزارش‌ها اثر هر سطر را با +/− یا خرید/فروش، ماندهٔ همان دارایی، ماندهٔ تومانی و طلای معادل ۷۵۰ نمایش می‌دهند. فیلتر برچسب اضافه و ماندهٔ نهایی به کارت‌های شبیه فاکتور تبدیل شد. ترتیب ستون‌ها، تاریخ/ساعت و خروجی مطابق گزارش‌اند.

اکسل فایل XLSX با متن فارسی، رنگ و ترتیب گزارش است. چاپ و PDF از همان جدول و کارت‌ها تهیه می‌شوند؛ در پنجرهٔ چاپ برای PDF گزینهٔ Save as PDF را انتخاب کنید. برای حفظ ظاهر فارسی، اعداد اکسل متن هستند.

ارزها فقط در معرفی ارزها مدیریت می‌شوند؛ معرفی کالا فهرست فشرده و خوانا با ستون گروه و فیلد گروه در پایین فرم دارد. نوع و ارز دریافت/پرداخت بانک یا صندوق ارزی خودکار انتخاب می‌شوند. منوی راست با بالا/پایین و Enter و برگشت با ESC است؛ Enter در فیلدهای گزارش به بعد می‌رود.

اطلاعات در مرورگر است؛ از پشتیبانی و بازیابی پشتیبان بگیرید. index.html، next-core.js، next-forms.js، next-ui.js، next-report.js، next-ui.css و fonts باید کنار هم باشند. تست منبع: node --test tests/*.test.cjs.
