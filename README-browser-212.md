# نسخهٔ مرورگر ۲۱۲ — تغییر شمارهٔ ۱

https://thumper9480-droid.github.io/hesabdari/?v=212

برنامه، موجودی، سرمایه اولیه، ثبت سند، گزارش‌ها، گروه‌ها، معرفی‌ها، اطلاعات، روز/تاریخ/ساعت، خروج.

گروه‌ها: بانک‌ها، صندوق‌ها، هزینه‌ها، درآمد، اقساط، افراد.
معرفی‌ها: معرفی کالاها، معرفی واحدها، معرفی دارایی، معرفی برچسب‌ها.
اطلاعات: تنظیمات و سوابق، پشتیبانی و بازیابی، آپدیت‌ها.

داده‌ها و عملکرد بخش‌ها حفظ شدند. اطلاعات نسخه فقط در تب مرورگر نمایش داده می‌شود. تست طبق درخواست قبلی اجرا نشد. پس از انتشار صفحه را تازه‌سازی کنید.
