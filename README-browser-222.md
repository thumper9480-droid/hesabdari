# حسابداری محمد صدرا — آپدیت ۲۲۲

تغییرهای ۶۵ تا ۶۹: نرخ و اثر عددی کارمزد در سطر بدون عبارت ثابت/متغیر؛ کارت مانده با عنوان و عدد بزرگ‌تر، مثبت سبز/منفی قرمز؛ حفظ آخرین گزارش و محل پیمایش در رفت‌وبرگشت میان منوها؛ حذف دو ستون تکراری طرف حساب از ریزگزارش؛ نمایش از کجا/به کجا در سربرگ، سطرها و چاپ فاکتور.

محاسبات و جهت دفتر مالی حفظ شده است. اطلاعات در مرورگر است؛ پشتیبان را از پشتیبانی و بازیابی بگیرید. حالت گزارش در همین نشست حفظ می‌شود. تست منبع: node --test tests/*.test.cjs.
