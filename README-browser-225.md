# حسابداری محمد صدرا — آپدیت ۲۲۵

تغییرهای ۱۰۵ تا ۱۲۰: محاسبهٔ مستقل نرخ هر عدد و مثقال طلا/نقره، نرخ تاریخی در سند و گزارش، گزارش کالا و کارمزد مشخص، کارت‌های چاپ، حذف برچسب گروه‌ها، اصلاح قرارداد و تک‌قسط، تسویهٔ فاکتوری و جدول ماهانهٔ ماندهٔ اقساط.

شمارهٔ فاکتور را تایپ و Enter بزنید. F1 فاکتور جدید، F3 اول اصلاح سربرگ و F3 بعد روی سطر اصلاح همان سطر است. ESC منوی اصلی و بالا/پایین و دو Enter برای ورود به صفحه. F12 ریزگزارش طرف سربرگ است.

در معرفی کالا واحد نرخ و مبنای محاسبه را انتخاب کنید: نقره ۴٫۶۰۸۳ گرم واقعی؛ مظنهٔ طلا ۴٫۳۳۱۸ گرم معادل ۷۵۰. مثقال فیزیکی صیرفی ۴٫۶۰۸۳ گرم است. خرید/فروش تعهد ایجاد می‌کند؛ موجودی فقط دریافت/پرداخت واقعی است.

قسط بدون پرداخت قابل حذف است. مبلغ قسط از پرداخت ثبت‌شده کمتر نمی‌شود و تغییر مشخصات اساسی قرارداد دارای تسویه نیازمند برگشت تسویه است. داده‌ها در مرورگر نگهداری می‌شوند؛ پشتیبان بگیرید. اطلاعات تاریخی ناموجود حدس زده نمی‌شود.

فایل‌های index.html، next-core.js، next-forms.js، next-report.js، next-ui.js، next-ui.css و fonts باید کنار هم باشند. تست: node --test tests/*.test.cjs؛ برای تست مرورگر، Chromium و Playwright و سرور python -m http.server 8015 لازم است. اسکریپت‌های browser225*.cjs با SADRA_BASE_URL نیز کار می‌کنند.
