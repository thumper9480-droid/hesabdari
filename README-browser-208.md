# نسخهٔ مرورگر ۲۰۸

https://thumper9480-droid.github.io/hesabdari/?v=208

در گروه‌ها: عنوان‌های بانک‌ها، صندوق‌ها، هزینه‌ها و درآمدها قرمزند؛ اقساط به گروه‌ها منتقل شده است. افراد و کالاها در منوی اصلی هستند. عنوان سند اولیه در منوی اصلی به سرمایه اولیه تغییر کرده است.

برچسب‌ها در گروه‌ها باقی است؛ منظور از «بررسی‌ها» و تغییر رنگ اقساط هنوز روشن نشده است.

داده و فرمول‌ها تغییر نکردند. تست بنا به درخواست قبلی اجرا نشد. پس از انتشار Ctrl+F5 بزنید.
