# نسخهٔ مرورگر ۲۱۱

https://thumper9480-droid.github.io/hesabdari/?v=211

تاریخچهٔ تغییرات اسناد و حساب اشخاص در منو نیستند؛ سوابقشان محفوظ است. پشتیبان‌گیری بلافاصله زیر آپدیت قرار دارد. نسخهٔ ۵.۹.۱، نسخه مرورگر و آپدیت ۲۱۱ در عنوان تب مرورگر نمایش داده می‌شوند. روز، تاریخ و ساعت زنده زیر لوگو قرار دارند؛ عبارت وقت ایران نمایش داده نمی‌شود و مبنای ساعت تغییر نکرده است.

تست بنا به درخواست قبلی کاربر اجرا نشد. پس از انتشار Ctrl+F5 بزنید.
