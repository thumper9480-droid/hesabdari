# حسابداری محمد صدرا — نسخهٔ مرورگر، آپدیت ۲۱۷

تغییرهای ۱۱ تا ۱۶: معرفی ارزها، واحد مقدار و نرخ کالا، قالب سه‌رقمی اعداد، دریافت/پرداخت کالایی مطابق معرفی کالا، اصلاح و حذف فاکتور و سطرها، کلیدهای F1 جدید / F2 سطر جدید / F3 اصلاح / F4 حذف / F5 چاپ.

index.html را با فایل‌های JavaScript و CSS و پوشهٔ fonts در کنار هم باز کنید. برای نسخهٔ آنلاین از GitHub Pages استفاده کنید. اطلاعات در مرورگر ذخیره می‌شود؛ پیش از جابه‌جایی مرورگر یا رایانه، از منوی پشتیبانی و بازیابی پشتیبان بگیرید.

سطرها ابتدا پیش‌نویس هستند و اثر مالی با ثبت نهایی ایجاد می‌شود. پس از F3 اثر نسخهٔ قبل تا ثبت نهایی اصلاحات باقی است. حذف و اصلاح دارای ردپای مالی است و در صورت ایجاد موجودی منفی یا وابستگی فعال، پیام مانع نشان داده می‌شود. مسیر خرید و فروش منتظر مشخصات بعدی است.
